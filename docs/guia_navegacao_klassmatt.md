# Guia de Navegação - Klassmatt (Rodonaves)

Este guia descreve os passos necessários para acessar o portal Klassmatt e navegar até as solicitações de alteração de itens (SAI).

## 1. Acesso e Login

1. Acesse o portal de SSO: [sso2.klassmatt.com.br/painel.aspx](https://sso2.klassmatt.com.br/painel.aspx)
2. Insira suas credenciais:
    * **Usuário:** `israel.machado`
    * **Senha:** `integra@2024`
3. Após o login, você verá o painel com os projetos disponíveis.

## 2. Seleção do Ambiente

1. No campo de pesquisa do painel, digite **"RODONAVES"**.
2. Clique no ícone ou link correspondente ao projeto **RODONAVES** para entrar no ambiente específico.

## 3. Navegação na Worklist (Acompanhamento)

Para visualizar as solicitações pendentes:

1. Acesse a aba ou seção de **Worklist** (Acompanhamento das Solicitações).
2. Clique no título: **"Acompanhamento das Solicitações (Worklist)"**.

## 4. Uso de Filtros

Para filtrar por tarefas específicas, como o setor Fiscal:

1. Localize o filtro de opções (geralmente um menu dropdown abaixo do título da página).
2. No campo de busca do filtro (Select2), digite **"klassmatt"**.
3. Selecione a opção: **"Solicitações que aguardam FISCAL-KLASSMATT e requerem minha atuação"**.

## 5. Acesso aos Itens

1. A lista de solicitações será atualizada com base no filtro.
2. Clique na descrição ou no ID do item desejado para abrir o **Resumo da Solicitação**.
    * Exemplo: Clique em `00013/95 ARGAMASSA CIMENTICIA PARA IMPERMEABILIZACAO` para ver os detalhes técnicos e fiscais.

---
> [!TIP]
> Caso a sessão expire (Logout automático), repita os passos de login no portal SSO para restabelecer o acesso ao ambiente Rodonaves.
